# Source Authority

| Truth | Default Authority |
|---|---|
| Intent | approved Requirement / Decision |
| Implementation | repository code / Git state |
| Runtime numeric/data truth | authoritative DB / CSV / Resource / API snapshot |
| Verification | version-bound TestRun evidence |
| Build identity | artifact metadata |
| Deployment | deployed artifact/runtime evidence |
| Human acceptance | explicit human decision |
| Status/wiki/checkpoint | derived projection |
| Harness version | harness release manifest |

If sources conflict, create a conflict record and block dependent claims if necessary. Do not silently choose.
