# Failure Taxonomy

`project_bug`, `agent_reasoning_failure`, `missing_context`, `bad_tool`, `bad_policy`, `bad_relation`, `bad_state_rule`, `bad_eval`, `environment_failure`, `external_dependency`, `human_decision_required`, `redundant_context_load`, `manual_workaround`, `test_selection_miss`, `stale_evidence_misuse`, `duplicate_side_effect`.

Create a harness requirement only when the issue is recurrent, structurally generalizable, or high severity.
