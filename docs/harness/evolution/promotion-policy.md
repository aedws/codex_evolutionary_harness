# Promotion Policy

Project promotion: local eval pass, rollback path, no stability-anchor violation.

Project → Domain: similar causal pattern in 2+ same-domain projects, project assumptions removed, domain eval pass, acceptable complexity cost.

Domain → Core: equivalent causal pattern across multiple domains, domain semantics removed, core regression pass, compatibility pass, rollback path.

Human review always required for root source authority, production permissions, credential scope, destructive capabilities, evidence retention weakening, eval integrity changes, human-verifiable boundary changes, rollback removal.
