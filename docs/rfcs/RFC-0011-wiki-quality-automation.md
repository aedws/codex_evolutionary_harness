# RFC-0011 — 생성부터 화면 관찰까지 위키 품질 판정

상태: v0.9.0 로컬 후보. TASK-20260915-SEED-QUALITY-001 / EXE-20260915-SEED-QUALITY-001. 수락 mixed.

## 문제와 목표

위키 생성 파일의 동일성만으로 큰 문서→주제→객체 탐색이나 화면 품질을 확인할 수 없다. Newgame 시각 참조에서 관찰한 목적·짧은 행동·접힌 기록·객체 연결을 반복 가능한 판정 항목으로 만든다. 프로젝트의 낡은 현재 안내는 선언한 출처의 버전 변경을 탐지하고 의미 충돌은 별도 검토한다. 특정 프로젝트의 금융 정보·키·문서를 씨앗에 복사하지 않는다.

## 판정 계층

1. 설치 자동 검사: 대문·9주제·6종 객체, 양방향 계층 탐색, 노드 지도, 카드, 상세 접기, 생성 근거, 단일 h1/viewport, 로컬 링크, 실행 콘텐츠 차단, 과도한 문단 길이를 실제 HTML에서 검사한다. 실패 시 설치 산출물을 만들기 전에 중단한다.
2. 프로젝트 출처 검사: 각 View에 실제 파일과 SHA-256 바인딩을 요구한다. 파일 누락/수정은 차단한다. 새 바인딩을 작성해도 이전 화면 검토는 snapshot 불일치로 재사용하지 못한다. 어떤 출처가 권위 있는지는 기존 source-authority가 소유한다.
3. 화면 관찰: 대문·주제·객체 각 390/1280 CSS px, 비교 참조 PNG, 페이지/이미지 해시, 관찰자, 잘림·텍스트·계층·노드 이동·접기 결과를 요구한다. 누락·실패·변경된 기록은 차단한다. 템플릿은 모든 판정을 false로 생성한다.
4. 완료 wrapper: project 모드 + 구조 통과 + 화면 관찰 기록 + 기존 bootstrap_ready가 모두 있어야 wiki_review_ready를 반환한다. human_pending은 유지한다. bootstrap.py/harness.py/권한 engine은 수정하지 않는다.

## 자동화와 한계

wiki_quality.py는 HTML과 증거를 검사하는 표준 라이브러리 CLI다. 브라우저 실행·스크린샷·시각 비교는 해당 프로젝트의 agent/browser 도구가 수행한다. 도구가 없거나 접근이 막히면 시각 단계 pending을 유지한다. 참고 사이트의 로그인/권한을 우회하지 않는다. PNG와 체크박스가 관찰자 신원이나 픽셀 의미를 암호학적으로 증명하지 않으며, AI 서술만으로 인간 수락을 만들지 않는다.

기본 한국어 템플릿의 필수 표제와 마커를 검사한다. 다른 언어/렌더러는 동등한 범위의 명시적 adapter 평가가 필요하다. 모든 역할의 접근 정책은 wiki_core/bootstrap/HTTP adapter가 담당한다. 이 검사는 완전한 역할별 비공개 문서 누출 검사를 대체하지 않는다. 외부 JS·iframe·form 등 동작이 필요한 위키는 기본 정적 프로필을 조용히 완화하지 말고 별도 보안·기능 평가를 제안한다.

## CLI·소유권·실패와 복구

설치 때 quality-contract.json과 quality.json을 생성된 초안과 함께 receipt에 묶는다. draft는 project gate를 통과하지 않는다. check는 읽기 전용이고 결과를 stdout에 출력한다. review-template은 미완료 양식을 stdout에 출력한다. gate는 로컬 기존 bootstrap CLI만 실행하며 네트워크/키/유료 호출이 없다. 실패 exit 2, 성공 exit 0. 같은 입력은 같은 구조 snapshot을 만든다. 결과 폴더에 수동 변경이 있으면 기존 draft 보존 규칙에 따라 새 출력 경로를 선택한다.

수동 입력: 프로젝트 품질 계약, 출처 바인딩, 관찰 기록. 생성 소유: HTML/품질 JSON/manifest. 버전은 v0.8.1→v0.9.0, contract6 유지, 새 component profile wiki-quality-1. 기존 설치를 자동 덮어쓰거나 policy를 다시 pin하지 않는다. 롤백은 기존 배포/출력/바인딩으로 명시적으로 돌아가고 새 근거와 실패 기록은 보존한다. wrapper는 자신의 실행 경로만 강제하며 외부 CLI 직접 호출이나 OS 권한을 봉쇄하지 않는다.

## 평가와 승격

두 도메인의 합성 초안, 누락 노드/계층/카드/지도, 깨진 링크/실행 마크업, 과도한 문단, 출처 변경, 화면 증거 없음/변경/중복/실패, draft 완료 오용, 정상 설치 재생/ZIP을 검사한다. Core는 사용자 요청에 따른 로컬 후보이며 장기 교차 프로젝트 일반성이나 외부 릴리스로 승격하지 않는다. 중복 수작업을 줄이되 시각·인간 판단을 허위 자동 통과로 바꾸지 않는 것이 기준이다.
