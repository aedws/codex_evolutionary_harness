# RFC-0010 — 객체 연결 지도를 기본 탐색 화면으로

상태: v0.8.1 로컬 배포 후보. Task TASK-20260915-SEED-GRAPH-001. 프로젝트 적용은 별도 TASK-20260915-WIKI-GRAPH-001이다.

오너는 객체 위키가 줄글 중심이라 관계를 이해하기 어렵다고 지적했다. 기존 객체·관계 원본은 유지하고 화면의 첫 계층을 노드와 방향선으로 구성한다. Newgame에서 참고한 큰 문서 → 주제 → 작은 객체 → 근거 구조에 관계 탐색을 추가한다. Newgame에 같은 그래프가 구현돼 있다고 주장하지 않는다.

선택한 객체를 가운데, 들어오는 관계를 왼쪽, 나가는 관계를 오른쪽에 표시한다. 노드에는 유형·이름·ID·목적 요약·검사 배지를 둔다. 노드를 클릭하면 해당 문서에서 지도가 다시 중심을 잡는다. 화살표는 기록된 from→to이고 관계 유형을 표시한다. 확인 근거와 추론/unknown 관계를 실선·점선 및 텍스트로 구분한다. 관계 확인은 노드 검사 통과·인간 수락·실행 권한이 아니다.

전체 대형 그래프를 한 화면에 겹치지 않는다. 기본 이웃을 방향별 네 개로 제한하고 생략된 이웃 수와 전체 관계 목록을 제공한다. 순환·자기 연결·고립 객체를 유효하게 표현한다. 줄글·상태 생성 계보·완전한 이름·근거·다음 행동은 상세 영역으로 보존한다. 카드별 클릭·키보드 탐색·가로 스크롤로 이동할 수 있으며 JavaScript·외부 CDN·LLM 호출이 필요 없다.

새 공통 renderer `wiki_graph.py`, profile `object-node-map-1`을 배포한다. 설치 자동 초안과 각 객체 문서의 기본 경로에 통합하고 해시를 manifest/claim에 연결한다. 초안 상태는 계속 unverified/interview_pending이다. 실제 프로젝트 adapter는 이미 허용된 노드 집합과 독립 reducer 결과만 공급한다. 숨겨진 노드의 이름·ID·관계·개수는 표시하지 않는다. 기존 접근 gate는 유지한다.

기존 v0.7 wiki_template와 pinned engine은 덮어쓰지 않는다. 기존 프로젝트는 공통 renderer와 동일 byte의 별도 프로젝트 adapter를 사용하고 버전 근거와 표현 검사를 등록한다. 이전 install receipt/초안은 변경하지 않고 새 폴더에 후보를 생성한다. 과거 v0.8.0 ZIP은 rollback 원본으로 남긴다. GitHub push·tag·release·운영 상위 승격은 이 로컬 후보 검증과 분리한다.

검사: 화살표 방향, 관계 근거/검사 상태 분리, 미연결·순환·고차수·생략 안내, 악성 문자열 escaping, 허용되지 않은 대상 비노출, 동일 입력 재생, 설치/ZIP 자동 출력, 링크/권한/원본 해시 보존. 화면의 직관성은 오너 수락 전 mixed/human_pending이다. 실제 프로젝트 한 곳의 사용성과 합성 두 도메인의 구조 검사는 장기 교차 프로젝트 운영 성과가 아니다.
