# 권한과 실행 경계

기본은 오프라인 로컬입니다. 계정·로그인을 만들지 않습니다. owner는 원본/작업 등록, 실제 검사 실행, MVP 판단, 채택, rollback을 수행합니다. proposer는 후보를, evaluator는 고정 비교 평가를 수행합니다. 세 label은 다르게 등록해야 합니다. label을 아는 로컬 사용자는 다른 label로 CLI를 호출할 수 있으므로 **신원 인증·적대적 다중 사용자 분리는 보장하지 않습니다**.

중요 규칙은 CLI에서 검사하지만 임의 셸·네트워크·자식 프로세스 전체를 통제하지 않습니다. 등록한 Python 검사 스크립트만 30초 제한, 최소 환경, 출력 보존 64KiB로 실행합니다. 테스트 코드 자체는 신뢰한 프로젝트 코드입니다. 외부 부작용을 가진 스크립트는 별도 승인이 있어야 하며 이 배포본은 그 외부 권한을 제공하지 않습니다.

모든 외부 쓰기·비용·배포·원격 upstream 제출은 비활성입니다. local backup은 원장만 복사하며 원본 데이터 백업과 구분합니다. 관측에서 권한을 추론하지 않습니다. V3는 aliases/context_order/output_format/module_navigation/checklist만 바꿀 수 있습니다.
